# Smart-Environment-and-Safety-Monitoring-System
Arduino UNO-based environmental and safety monitoring system with a Python dashboard.

## Project Overview
An Arduino UNO-based system designed to monitor environmental conditions and safety monitoring features.

## Hardware Components
- Arduino UNO
- DHT11 Temperature and Humidity Sensor
- MQ-2 Gas and Smoke Sensor
- NEO-6M GPS Module
- OLED Display
- HC-05 Bluetooth Module (if used)

## Repository Structure
- Source_Code/ — Arduino and Python source files
- Report/ — Final project report

## How to Use
1. Open the Arduino source file in Arduino IDE.
2. Connect the sensors according to the circuit diagram.
3. Select the correct Arduino board and COM port.
4. Upload the program and observe the output.

## Documentation
Refer to the report in the Report folder for project details, circuit connections, methodology, and results.
